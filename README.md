# qummy-wheel-single-page

Одностраничная версия исходного промо с колесом и экраном результата.

Сохранены исходные тексты, стили, шрифты и графика.

Изменено только:
- удален первый экран ввода телефона;
- всё сведено в один `index.html`, один `style.css`, один `script.js`;
- удалена отправка/сохранение результата во внешние сервисы.
